# Pacing coalescing order cost-uncertainty artifacts

This directory contains the compact E86 local-only cost-estimation uncertainty audit built from E83–E85.

- `pacing_coalescing_order_cost_uncertainty_full.json` records exact nominal, compressed, fixed, and uncertainty-aware member-order results for radius-0/1/2 ordinal cost errors.
- `SHA256SUMS` records the promoted raw artifact digest.

For each estimated marginal-cost point, radius `r` admits actual points at most `r` grid indices away. The robust policy minimizes maximum cell regression, then maximum delay, aggregate regression count, acceleration count, and deterministic order rank. Results report every admissible pair and an adversarial one-estimate-per-actual-metric envelope.

The source allocation remained canceled, so this is not new GPU evidence and was not promoted to durable AML storage.
