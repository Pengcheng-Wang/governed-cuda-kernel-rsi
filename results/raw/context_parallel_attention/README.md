# E115: Long-Context Distributed Attention & Hybrid 2D Context Parallelism (`CP = 2, 4, 8`)

Measured on a single 8x NVIDIA A100-SXM4-80GB (NV12 NVSwitch) node at locked `1410 MHz` target SM clocks across **3 independent OS-process repetitions** (`rep1`, `rep2`, `rep3`) plus a multi-GPU smoke gate (`smoke_context_parallel_attention.json`).

## Files

- `smoke_context_parallel_attention.json` — `CP = 2, 8` multi-GPU correctness, chain-rule, and `torch.profiler` smoke gate.
- `rep1_context_parallel_attention.json` .. `rep3_context_parallel_attention.json` — three independent `CP = 1, 2, 4, 8` process repetitions across `S = 8,192` to `131,072` (`8K` to `128K` tokens).
- `context_parallel_attention_full.json` — deterministic 3-repetition median summary and 9-gate validation generated by `code/analyze_context_parallel_attention.py`.
- `SHA256SUMS` — SHA-256 manifest for all 5 JSON artifacts.

## Suites Covered

1. **Suite 0 (`suite_0_pytorch_cp_audit`)**: Audits PyTorch 2.13 `torch.distributed.tensor.experimental._attention.context_parallel` (`default_rotate_method = ALL_GATHER`, empty-`buffers` `IndexError` bug, `c10d` element volume, and eager `_SDPAMerger` overhead) against native 8-KV-head FlashAttention-2 Zig-Zag Ring (eager vs fused Triton online-softmax LSE merger) and GQA-native Ulysses at `S = 32,768` (`CP = 2, 4, 8`).
2. **Suite A (`suite_a_sequence_scaling`)**: Decomposes causal Ring load imbalance (`ring_contiguous_overlap` vs `ring_zigzag_seq`), double-buffered `(K, V)` and `(K, V, dK, dV)` P2P overlap (`ring_zigzag_overlap`), naive 32-head KV-expanded vs 8-head GQA-native DeepSpeed-Ulysses (`ulysses_kv_expanded`, `ulysses_gqa_native`), and Hybrid 2D Unified Sequence Parallelism (`usp_u2_r2`, `usp_u2_r4`, `usp_u4_r2`) from `S = 8,192` to `131,072` (`CP = 1, 2, 4, 8`).
3. **Suite B (`suite_b_sparse_gqa_wall`)**: Evaluates the `CP > H_kv` head-sharding wall on `CP = 8` across `H_kv = 8, 4, 2, 1` (`GQA-4` through `MQA`) at `S = 32,768` and `65,536`, comparing KV-replicated `U = 8` Ulysses against `U1xR8` Zig-Zag Ring and replication-free `USP(U = H_kv, R = 8 / H_kv)`.
4. **Suite C (`suite_c_llama3_block`)**: End-to-end Llama-3-8B GQA Transformer block training (`H = 4096, FFN = 14336, 32Q/8KV, D = 128`, with RoPE, compiled `RMSNorm` + `SwiGLU`, and both pure-CP and full `dW` `AllReduce` synchronization) across `S = 16,384` to `131,072` (`16K` to `128K` tokens), including 32-layer activation memory projections and exact single-GPU `out`/`dx`/`dW`/`1.75x` chain-rule checks.
