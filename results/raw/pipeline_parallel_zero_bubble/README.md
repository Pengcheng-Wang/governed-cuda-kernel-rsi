# E116 — Pipeline Parallelism, Zero-Bubble & DualPipe-V `dX`/`dW` Splitting, and Selective Activation Checkpointing

Raw and aggregated JSON artifacts for **E116**, measured on **8x NVIDIA A100-SXM4-80GB (NV12 NVSwitch)** at hardware-locked `1410 MHz` SM clocks using a 16-layer Llama-3-8B-width GQA Transformer (`H = 4096, FFN = 14336, 32Q/8KV, D = 128`, `BF16`).

## Files

- `smoke_pipeline_parallel_zero_bubble.json`: 8-GPU 16-layer smoke-gate verification (`PP = 1, 4, 8`, all schedules, audits, and AC/SAC modes).
- `rep1_pipeline_parallel_zero_bubble.json` .. `rep3_pipeline_parallel_zero_bubble.json`: Three independent OS-process repetitions of the full `PP = 1, 4, 8` matrix (`M = 8, 16, 32`, `S = 1024..8192`).
- `pipeline_parallel_zero_bubble_full.json`: Deterministic 3-repetition median summary and 9-gate validation output generated by `code/analyze_pipeline_parallel_zero_bubble.py`.
- `SHA256SUMS`: SHA-256 manifest covering all publishable JSON files in this directory.
