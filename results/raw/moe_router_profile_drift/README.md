# Trained-router profile drift and spill fallback

This directory evaluates fixed expert-parallel transport profiles with router
traces from the open `allenai/OLMoE-1B-7B-0924` checkpoint.

- The corpus contains 480 deterministic, original template samples across ten
  ordered domains. Prompt text is regenerated by source code and is not stored.
- Each sample has 128 valid tokens. Counts cover all 16 trained MoE layers,
  64 experts, and top-8 routing.
- The first four domains calibrate profiles; the remaining six evaluate domain
  drift. Expert IDs are mapped contiguously to logical 8- and 24-rank
  topologies.
- Static and sliding-window profiles compare fixed per-cell additive margins
  with row-budget risk allocation. Profile construction uses only past steps.
- A miss never clips model output. The distributed benchmark keeps accepted
  assignments in fixed tile-512 slots and sends excess assignments through an
  exact variable-split metadata-packed spill side channel.
- Two position-balanced crossover runs were completed on 8 and 24 A100 GPUs.
  Assignment partitioning is exact. The largest BF16 output difference from
  fully dynamic transport is one half-precision rounding quantum.

The main finding is negative: lower-row risk profiles spill too often, and the
overflow guard, count exchange, extra collectives, and second expert launch
cost more than the saved padded rows.
